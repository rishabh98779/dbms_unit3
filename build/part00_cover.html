How to use it in one day

  1. Morning, 3 h — Sections 1–4. Read each definition aloud once, then close the page and rewrite the ACID table and the four concurrency problems from memory.
  2. Afternoon, 3 h — Sections 5–8. Draw 2PL, the timestamp rules and the log-recovery flow on blank paper. These carry the high-weight diagram and numerical questions.
  3. Evening, 2 h — Sections 9–11. Learn the PL/SQL syntax blocks, then answer only the “Exam Focus” questions.
  4. Last 30 min — Section 12. Checklist and comparison table only. Do not open new topics.

Six rules for full marks

1Open with the definition — the first mark is always for it.
2Draw the diagram even when it is not asked, and label every box.
3Put numbers in examples: ₹ amounts, timestamps, log records.
4Compare in a table, never in a paragraph.
5Name the algorithm (2PL, TO, deferred update) before explaining it.
6Close with its limitation — deadlock, cascading rollback, overhead.
